    Classic mix-up to avoid

    RAM is working memory — fast, small and wiped on power-off. Storage (SSD/HDD) is the warehouse — slower, large and keeps data without power. A program must be copied from storage into RAM before the CPU can run it.

    How the parts talk to each other

    The SoC is the traffic centre. The camera's ISP writes processed frames into shared memory, the GPU reads them, the display controller sends them to the panel, and the modem hands network data over the same memory bus — all scheduled by the operating system.

      Why this order matters

      The CPU can only execute instructions that are already in RAM. Storage is far too slow to feed a CPU core directly, so the operating system copies the program in, then the CPU jumps to its first instruction. Graphics are a second pipeline: the GPU builds an image in VRAM and the display controller streams it to the screen.

      Stage log

        Simplified model vs. a real operating system

        Real launches involve a scheduler, virtual memory and page tables, device drivers, file-system caching, a compositor and the window system. This simulator shows the essential data path in order, with no caches, no interrupts and no multiprocessing — that keeps the idea teachable.

                  Quick guide

                  TECHVERSE has nine sections. Use the numbered navigation strip, or these shortcuts:

                  • 1 Computer Lab — CPU, RAM, storage, GPU, motherboard and peripherals.
                  • 2 Smartphone Lab — SoC, memory, battery, display, camera, radios.
                  • 3 Disassembly Bay — explode a laptop or phone and tap the parts.
                  • 4 Data Journey — the animated launch sequence, with speed control.
                  • 5 Experiment Lab — six stress tests with sliders.
                  • 6 PC Builder — compatibility checks and a live assembly preview.
                  • 7 Knowledge Centre — the searchable encyclopedia.
                  • 8 Assessments — quizzes that save progress locally.

                  Keyboard: 1–9 switch sections, Space plays or pauses the current animation, Esc closes dialogs. Everything works offline.
